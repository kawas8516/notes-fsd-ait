# Instructions for React Notes (freeCodeCamp)

Reference doc for how each module's notes should be written. Use this before writing or revising any module.

## Writing style

- Rewrite source text clearly, structured, easy to read, and logically organised — not a copy-paste of the original.
- Keep some own words and genuine reflection. Don't just rephrase the source; add your own understanding.
- Technical language is fine. Avoid unnecessary jargon.
- In code snippets, explain with short inline comments instead of long prose explanations below the code.
- Keep formatting minimal: use headings to group related ideas, but don't over-format with excessive bullets or bold text.

## Required elements per module

Every module's notes must include all five of the following. Missing any one of these counts as incomplete:

1. **Overview** — what the module/topic is about, in a few sentences.
2. **Examples** — working code examples with inline comments, matching what's taught.
3. **Key terms** — a short list of terms introduced, defined in your own words.
4. **Use case** — a sentence or two on when/why you'd actually use this in a real project.
5. **Aha moment** — a genuine personal reflection: something that clicked, a misconception corrected, or a comparison to something already understood. This must show real engagement, not a restated summary.

## Structure and labelling

- Label each module clearly by module name/number and date.
- Organise notes logically within a module (e.g. concept → syntax → example → reflection).
- Keep a consistent structure across modules so they're easy to scan later.

## Grading rubric (self-check before finalizing)

1. All modules covered with all required elements (overview, examples, key terms, use case, aha moment).
2. Concepts, syntax, and code examples are accurate and demonstrate understanding.
3. Notes are clearly structured, labelled by module and date, easy to read, and logically organised.
4. Notes are in the student's own words with genuine reflection; aha moments show personal engagement — no superficiality.
